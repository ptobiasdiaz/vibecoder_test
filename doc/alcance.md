# Alcance y decisiones

Este proyecto valida el bootstrap de vibecoder mediante una base Python mínima y ejecutable.

Se utiliza Python 3.11 o posterior, una función `sumar(a, b)` en `src/` y una prueba en `tests/`. La prueba usa `unittest`, incluido en Python, por lo que no se requieren dependencias de terceros ni instalación del proyecto.

No se incluyen servicios externos ni base de datos. Las instrucciones de ejecución se encuentran en el [README](../README.md).

La documentación para usuarios y desarrolladores reside en `doc/`. El contexto operativo y la memoria versionada del bootstrap residen en `.vibecoder/`.
