# Reglas globales

- Mantener un proyecto mínimo de prueba para validar el bootstrap de vibecoder con Python 3.11 o posterior y sin dependencias de terceros.
- Usar `src/` para el código y `tests/` para las pruebas con `unittest`.
- Mantener un README claro y la documentación pública en `doc/`.
- Guardar el contexto operativo y la memoria versionada en `.vibecoder/`.
- No añadir servicios externos ni bases de datos.
- Trabajar exclusivamente dentro del workspace actual, sin ampliar el alcance aprobado.
- No ejecutar Git, realizar operaciones remotas ni publicar desde Codex.
- No crear archivos vacíos, secretos, credenciales, sesiones, bases de datos, logs ni cachés.
